这个站点由 **marklite** 生成 —— 一个不依赖任何 npm 包的静态站点生成器。
它做三件事：读 Markdown、套模板、写 HTML。

## 为什么自己写解析器

现成的解析器当然更完整，但一个博客需要的东西其实很少：

- 标题、段落、列表
- 代码块（能标语言就够）
- 表格
- 引用
- 链接和图片

这些加起来不到 300 行。换来的是：`git clone` 之后直接能跑，不需要 `npm install`，
也没有三年后依赖树烂掉的风险。

> 依赖不是免费的。每引一个包，就欠下一笔未来的维护债。

## 支持范围

写清楚**不支持**什么，比列一堆特性更有用：

| 语法 | 支持 | 说明 |
| --- | --- | --- |
| 标题 / 段落 / 强调 | 是 | 常规用法 |
| 围栏代码块 | 是 | 保留语言标签 |
| 表格 | 是 | 支持左/中/右对齐 |
| 嵌套列表 | 否 | 只有一层 |
| HTML 块 | 否 | 需要就直接写进模板 |

## 代码块长这样

```js
import { renderMarkdown } from 'marklite/markdown';

const html = renderMarkdown('# 你好\n\n这是一段**正文**。');
```

行内代码也一样：`renderMarkdown(source)` 返回 HTML 片段，不包 `<html>`。

## 换行与空格

GitHub 风格的软换行是可选的，这里按标准 Markdown 处理：单个换行不产生 `<br>`，
两个以上空格结尾才会强制换行。  
这一行末尾有两个空格，所以它和上一行是分开的。
